# 📊 Sales Performance Analysis Dashboard

## Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis performa penjualan produk dan kategori menggunakan **SQL** untuk logika data dan **Tableau** untuk visualisasi interaktif.

##  Sumber Data
Data yang digunakan dalam analisis ini berasal dari W3Schools SQL Tutorial Database.

## File Project
- analysis_queries_products.sql: Berisi kumpulan query SQL yang digunakan untuk memproses data.
- master_data.csv: File hasil olahan yang di-import ke Tableau.
- Dashboard.png
- Link Dashboard https://prod-apsoutheast-c.online.tableau.com/#/site/revinaadhisafitri-0927bc675c/workbooks/781603?:origin=card_share_link

## Tools Used
- **Database:** CSV / SQL(CMD)
- **Visualization:** Tableau Cloud / Tableau Public
